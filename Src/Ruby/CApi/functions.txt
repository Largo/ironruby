# The C API functions IronRuby implements in C# (Src/Ruby/CApi/CApi.*.cs, one static method of
# the same name each). Util/capi/generate.rb turns each prototype into an exported C forwarder
# (native/forwarders.generated.c) and an [UnmanagedCallersOnly] entry point (CApi.Generated.cs).
# The prototypes are CRuby 4.0's, as `ruby Util/capi/prototypes.rb <name>` prints them; the
# shim includes ruby.h, so a mismatch is a compile error. Variadic functions and the ones that
# catch a raise are C (native/capi.c); every other function the headers declare and nothing
# here implements raises NotImplementedError (native/build: stubs.generated.c).
