
Removed from the vendored copy because MRI implements them as C extensions
(or on top of one), so the 1.9 pure-Ruby versions behind them on the load
path are the working ones here:
  pathname.rb  - the Pathname class is pathname.so; 4.0's .rb is a stub
  yaml.rb      - delegates to psych.so; IronRuby has its own YAML library

Patched in place (uri/common.rb reaches these through require_relative, so a
shim elsewhere on the load path cannot shadow them):
  uri/rfc3986_parser.rb - the \g subexpression calls (none recursive) in the
                          HOST and RFC3986_URI/relative_ref regexps written out
                          inline, which is exactly equivalent
  uri/mailto.rb         - one non-recursive \g<hfield> reference expanded
                          inline, which is exactly equivalent

Added from the gems MRI 4.0 ships (lib/ copied verbatim):
  logger.rb, logger/ - logger 1.7.0 (a bundled gem since 3.5)
  csv.rb, csv/       - csv 3.3.5 (a bundled gem since 3.4)
  getoptlong.rb      - getoptlong 0.2.1 (a bundled gem since 3.4)
